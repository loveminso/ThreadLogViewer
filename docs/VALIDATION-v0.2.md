# v0.2.0 검증 기록 — 2026-09-16

## 변경

워크벤치 화면, 다크/라이트 팔레트, 아이콘 툴바, 정리된 스레드 목록, 통합 상태줄, 기본/좁은 행 간격. 파서·필터·내보내기 핵심 로직 변경 및 신규 패키지 추가 없음.

## 빌드 및 자동 테스트

- Windows x64, 프로젝트 내부 .NET SDK 10.0.401 / 런타임 10.0.12.
- `build.cmd`: Release 성공, 경고 0 / 오류 0.
- `test.cmd`: **36개 통과**, 실패 0, 건너뜀 0.
- 기존 33개 회귀 테스트에 두 테마의 글자 대비 검사와 실제 AvalonEdit 행 높이 검증 추가.
- 로그 본문·미분류 행·보조 글자·기본 버튼·검색 강조·선택 영역의 검사 대상 색상은 대비 4.5:1 이상.
- 행 간격 변경 시 원문, 문서 인스턴스, 선택 길이, 문서 줄 수 보존 확인. 한글 행과 빈 행 모두 실제 렌더링 높이가 달라짐을 확인.
- 초기 NuGet 접속 제한으로 빌드 복원이 실패하여 승인된 개발용 네트워크로 재실행. 취약성 확인을 비활성화하지 않음.

## 실제 GUI 확인과 미확인

- 실제 Release WPF 창에서 `samples/mixed-utf8.log` 17줄을 열고 다크 화면, 아이콘 툴바, 스레드 색상·개수·최초/마지막 시각, 한글·빈 줄·원본 줄 번호, 상태줄, 긴 행의 가로 스크롤바를 관찰.
- 행 간격 드롭다운이 테마 색상으로 표시되고 두 옵션이 나타남을 확인.
- 사용자가 물리 Esc 키로 Computer Use를 중단하여 이후 GUI 입력을 진행하지 않음.
- **이번 변경 후 라이트 테마 전환, 좁은 간격 선택, 검색·필터·복사·내보내기의 전체 GUI 회귀는 미완료.** 자동 테스트 통과와 실제 GUI 확인을 구분함.
- 100% 외 다른 DPI, 다른 Windows PC, 시스템 고대비 모드, 장시간 사용은 미확인. 테마/간격 선택은 재실행 후 저장되지 않음.
- 기존 v0.1 GUI 검증과 성능 수치는 [이전 기록](VALIDATION.md) 참조. v0.2의 열기·필터·메모리는 재측정하지 않음.

## 구현 참고

행 간격은 [WPF FontFamily의 복합 글꼴 및 LineSpacing](https://learn.microsoft.com/en-us/dotnet/api/system.windows.media.fontfamily?view=windowsdesktop-10.0)을 사용한다. 실제 AvalonEdit 시각 행 높이를 자동 검증해 단순 속성 값 확인과 구분한다.
