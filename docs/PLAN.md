# 구현 범위와 후속 계획

## v0.1 기반 기능

1. Windows x64, C# / .NET 10 / WPF / AvalonEdit. UI 앱, Core, Tests의 3개 프로젝트.
2. 파일 전체를 한 번 디코딩하고 원본 문자열에 대한 행/필드 슬라이스와 스레드 요약을 생성.
3. 표시 인덱스와 원본 줄 번호를 분리. 필터는 파싱 결과만 사용하며 원본 순서를 보존.
4. 읽기 전용 AvalonEdit, 다중 행 선택·복사, 줄바꿈, 글자 크기, 고정폭 글꼴.
5. 고정 스레드 색상, 체크박스 필터, 최초/마지막으로 관측한 유효 시각. 날짜·생성 시점·실행 기간은 추론하지 않음.
6. 현재 표시된 문자열의 검색·강조·순환 이동. 원본과 다른 새 파일로 UTF-8 내보내기.
7. 읽기·파싱·필터 문서 생성·검색·내보내기는 백그라운드에서 실행. 취소 토큰과 세대 번호로 최신 결과만 게시.
8. 합성 테스트, 빌드·GUI 검증 구분, 10/100 MiB 성능 측정, self-contained 폴더 ZIP.
9. 파일 드래그 앤 드롭 및 파일/로그 텍스트 붙여넣기. 텍스트 입력은 실제 원본 경로가 없는 읽기 전용 문서로 처리하고 기존 로딩·취소·최신 결과 게시 흐름을 공유.

## v0.2 워크벤치 UI

- WPF 컨트롤 스타일을 통일하고 다크/라이트 테마, 얇은 툴바, 통합 상태줄을 적용.
- 스레드 색상은 같은 ID에 같은 팔레트 위치를 사용하며 테마에 맞춰 명도를 조절.
- WPF 복합 글꼴의 줄 간격으로 기본/좁은 간격을 제공. 원본 텍스트·복사·줄 번호는 변경하지 않음.
- 추가 UI 패키지나 웹 런타임 없이 기존 WPF/AvalonEdit를 유지.

## 후속 기능 (미구현 버튼을 만들지 않음)

- 별도 메모장 편집 탭: 원본 뷰어와 별도 문서/저장 수명주기.
- 타임라인: 날짜 누락과 자정 통과·시계 역행 구분 정책부터 설계.
- 선택 시점의 전체 스레드 보기.
- 시간 차이: 원본 시각의 정밀도와 날짜 불확실성을 표시.
- 북마크.
- 실시간 따라가기: 파일 교체, 부분 행, 회전 처리.
- 대용량 최적화: 메모리 매핑/구간 로딩/표시 투영 증분 처리. 백그라운드 문서 생성도 작은 청크로 취소 가능하도록 개선.

## 검증 원칙

자동 테스트, 실제 GUI 조작, 콘솔 벤치마크를 각각 기록한다. 예상 시간이나 예상 메모리는 측정값으로 보고하지 않는다.
