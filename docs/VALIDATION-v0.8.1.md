# v0.8.1 북마크 제거 검증 — 2026-10-07

북마크 메뉴·패널·단축키·줄 표식과 관련 상태·저장 모델을 제거했다. Release 빌드 경고 0/오류 0, 전체 자동 테스트 337/337 통과. 합성 비표시 WPF 렌더링을 확인했으며 실제 GUI 입력·모니터 DPI와 새 성능 측정은 미실행이다.

## 제거 범위와 호환성

- 왼쪽 북마크 패널·목록, 분석·우클릭 메뉴, 이름 변경, F2·Shift+F2·Ctrl+F2 처리와 줄 여백 마커 제거.
- `BookmarkState`·`SavedBookmark`, 탭별 북마크와 펼침 상태, 닫은 탭 보관 추정, 파일 새로 고침 비교·복사·위치 매핑에서 관련 처리 제거.
- 분석 상태 schema 1을 유지한다. 이전 JSON의 `Bookmarks`·`BookmarksExpanded`는 알 수 없는 필드로 무시하고 나머지 상태를 복원한다. 새 분석 JSON에는 이 필드를 생성하지 않는다.
- 원본·기존 분석 파일은 변경하지 않는다. 화면 설정 저장 위치와 형식도 유지한다. 검색·원본 줄 이동·탐색 이력·필터·강조·시간·분리 탭은 유지한다.
- 우클릭의 원본 줄 이동 항목을 상위로 옮기고 현재 사용법·도움말·단축키 표를 맞췄다. 과거 버전 검증 기록은 보존했다.

## 빌드와 자동 테스트

프로젝트 내부 .NET SDK와 기존 NuGet 캐시만 사용했다. 다운로드·도구 설치 없이 Release `build --no-restore -m:1 -nr:false` 완료 후 `test --no-build --no-restore`를 실행했다. 테스트 호스트는 로컬 IPC만 사용하며 실제 로그·클립보드를 조작하지 않았다.

| 검증 | 결과 | 기록 |
|---|---|---|
| 최종 Release 빌드 | 경고 0/오류 0 | App/Core/Tests, .NET 10 |
| 전체 자동 회귀 | 337/337 통과, 실패 0, 건너뜀 0 | [final-r3-v0.8.1.trx](../TestResults/v0.8.1/final-r3-v0.8.1.trx) |
| 북마크 제거 검증 | 8개 통과 | BookmarkRemovalTests: 두 테마 메뉴·패널·상태·여백 속성 부재, F2 계열 미처리, F3/F4 방향 유지 |
| 구 분석 파일 호환 | 4개 통과 | LegacyAnalysisCompatibilityTests: schema 1의 유효·null·다른 형식 북마크 무시, 새 JSON 필드 부재, 실제 분리 범위 분석 복원 |
| 기존 기능 | 파싱·물리 줄 매핑·필터·인코딩·원본 보호 내보내기와 탭·검색·새로 고침 회귀 통과 | 위 전체 TRX |

v0.8.0의 326개에서 제거한 기능 자체를 검증하던 1개를 삭제하고 새 12개를 추가했다. 다른 테스트에서는 북마크 준비·검증만 정리하고 선택·검색·문맥·시간·필터·취소·원본 보호 검증을 유지했다. 실패 입력과 새로 고침 취소에서는 커서 위치 보존 검증도 유지했다.

처음 두 통합 실행은 각 336/337이었다. 새 합성 레거시 fixture의 선택 영역과 커서 위치를 실제 저장 상태처럼 일치시키고, 공용 dispatcher의 비표시 창들이 공유하던 라디오 그룹을 창별로 격리했다. 선택 복원과 `AnalysisTool=1` 검증을 유지한 뒤 최종 실행이 통과했다. 초기 TRX는 보존하며 통과 기록에 섞지 않는다.

## 합성 화면과 실제 GUI

[944×452 다크](../TestResults/v0.8.1/bookmark-removal/small-window-dark.png), [944×452 라이트](../TestResults/v0.8.1/bookmark-removal/small-window-light.png)를 직접 확인했다. 북마크 패널·표식이 없고 검색·스레드·본문·상태 안내를 표시한다. 작은 화면에서 본문 최소 120 DIP와 스레드 목록 최소 96 DIP를 자동 검사했다. 기존 반응형 렌더링 4장도 생성했으며 독립 검토에서 1040×600 다크와 944×484 라이트를 확인했다.

비표시 WPF/bitmap 확인이다. 실제 프로그램 창에서 마우스·키보드·팝업·클립보드 조작이나 실제 모니터 125~200% DPI 전환은 실행하지 않았다.

## 측정 성능

이번 기능 제거에 대해 새 성능·메모리 벤치마크는 실행하지 않았다. 이전 측정은 [v0.8.0 검증 기록](VALIDATION-v0.8.0.md)에 보존하며 이번 버전의 측정값으로 보고하지 않는다. 자동 테스트 실행 시간도 사용자 입력 응답 시간으로 해석하지 않는다.

## 배포와 독립 검토

새 로컬 폴더 `artifacts/ThreadLogViewer-v0.8.1-win-x64`와 ZIP `artifacts/ThreadLogViewer-v0.8.1-win-x64.zip`을 사용한다. self-contained win-x64 publish를 기존 캐시로 완료했으며 EXE/DLL은 `0.8.1.0`, 포함 .NET/WPF는 `10.0.12`다. 이전 v0.8.0 폴더·ZIP은 보존한다.

배포 폴더와 ZIP의 파일별 SHA-256·파일 수·버전·금지 파일 검사 결과는 로컬 `artifacts/verification-v0.8.1.json`에 기록한다. 배포·테스트 산출물·개발 캐시·사용자 설정은 Git 커밋에 포함하지 않는다.

독립 reviewer가 제거 diff와 호환성 테스트, 현재 사용 문서, 합성 PNG 및 최종 TRX를 확인한다. 실제 GUI와 성능을 자동 테스트 통과로 보고하지 않는다.
