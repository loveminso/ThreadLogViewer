# ThreadLog Viewer 단축키

기준: v0.8.0 · 작성일: 2026-10-06

널리 쓰이는 파일·탭·검색·이동·북마크 단축키를 사용한다. 상단은 파일 / 편집 / 보기 / 분석 / 도움말 메뉴이며 동작 옆에 단축키를 표시한다. 단축키를 직접 지정하는 기능은 후속 범위이며 이번 버전에는 포함하지 않는다.

| 단축키 | 동작 | 적용 위치 / 참고 |
|---|---|---|
| `Ctrl+N` | 새 빈 탭 | 파일 → 새 탭 또는 탭줄 오른쪽 +와 같다. 입력창에 포커스가 있어도 새 읽기 전용 입력 탭을 만든다. |
| `Ctrl+O` | 로그 파일 열기 | 파일 → 파일 열기. 현재 빈 탭을 첫 성공한 파일로 채우고 이후 파일은 각각 읽기 전용 탭으로 연다. |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 다음 / 이전 탭 | 보기 메뉴에도 있다. 탭별 분석 상태와 위치를 복원한다. |
| `Ctrl+W` | 현재 탭 닫기 | 파일 → 현재 탭 닫기. 다른 탭은 유지한다. 마지막 탭을 닫으면 빈 화면으로 돌아간다. |
| `Ctrl+Shift+T` | 최근 닫은 탭 복원 | 파일 메뉴에도 있다. 현재 실행 중 최근 8개·추가 보관 추정 128 MiB 안에서 원문과 분석 상태를 복원한다. |
| `F5` | 상태를 유지하며 파일 새로 고침 | 전체 파일 탭에서 인코딩 선택·필터·검색·강조를 유지한다. 북마크·위치는 변경된 원문에서 다시 확인한다. |
| `Alt+←` / `Alt+→` | 탐색 뒤로 / 앞으로 | 검색·북마크·줄 이동을 탭별 최대 100개 기록한다. 새 이동을 하면 앞으로 이력을 비운다. |
| `Alt+F4` | 프로그램 종료 | 파일 → 종료. 재실행 후 복원하려면 먼저 파일 → 분석 상태 저장을 사용한다. |
| `Alt+F` / `Alt+E` / `Alt+V` / `Alt+A` / `Alt+H` | 파일 / 편집 / 보기 / 분석 / 도움말 메뉴 열기 | 메뉴 항목으로 이동해 Enter로 실행한다. |
| `Ctrl++` / `Ctrl+-` | 글자 크기 크게 / 작게 | 보기 → 글자 크기. 숫자 키패드 + / −도 지원한다. |
| `Ctrl+0` | 기본 글자 크기 14로 복원 | 보기 → 글자 크기 → 기본 크기. |
| `Ctrl+F` | 검색창으로 이동 | 현재 검색어를 선택해 바로 바꿀 수 있다. |
| `F3` | 다음 검색 결과 | 결과를 원본 위치로 이동하며 끝에서 순환한다. |
| `F4` | 이전 검색 결과 | 사용자가 요청한 기본 이전 검색 단축키. |
| `Shift+F3` | 이전 검색 결과 | 기존 동작의 별칭을 유지한다. |
| `Enter` / `Shift+Enter` | 다음 / 이전 검색 결과 | 검색창에 입력 포커스가 있을 때 사용한다. |
| `Esc` | 줄 이동창 / 검색창 닫기 | 줄 이동창이 열려 있으면 먼저 닫고, 다음 `Esc`로 검색창을 닫는다. |
| `Ctrl+G` | 원본 줄 번호로 이동 | 필터 후 표시 줄 번호가 아닌 원본 로그 줄 번호를 입력한다. |
| `Ctrl+F2` | 현재 원본 줄 북마크 켜기 / 끄기 | 로그 본문에서 사용한다. |
| `F2` / `Shift+F2` | 다음 / 이전 북마크 | 원본 줄 순서로 순환한다. 숨긴 위치는 주변 로그로 연다. |
| `Ctrl+A` | 전체 선택 | 로그 본문에서는 현재 표시 텍스트, 입력창에서는 입력 텍스트를 선택한다. |
| `Ctrl+C` | 선택 텍스트 / 선택 행 복사 | 행 선택은 원본 순서와 실제 개행으로 복사하고 숨긴 중간 줄·여백 번호는 포함하지 않는다. 입력창에서는 일반 복사. |
| `Ctrl+클릭` | 떨어진 물리적 줄 선택 / 해제 | 줄 번호 또는 로그 본문을 클릭한다. 이미 선택한 줄은 해제하며 다른 선택 줄은 유지한다. |
| `Ctrl+V` / `Shift+Insert` | 붙여넣은 로그 열기 | 로그 화면에서는 빈 탭을 채우거나, 로그가 있으면 새 읽기 전용 탭을 연다. 입력창에서는 일반 텍스트 붙여넣기를 사용한다. 편집 → 붙여넣기도 같은 로그 열기 동작이다. |
| `Ctrl+Shift+V` | 클립보드 로그 열기 | 파일 메뉴에 있다. 입력창에 포커스가 있어도 빈 탭을 채우거나 새 로그 탭을 연다. |
| `Shift+F8` | 선택 문구 / 커서 단어 즉시 강조·해제 | 창을 열지 않는다. 같은 문구는 대소문자 구분 없이 기존 규칙을 삭제하고, 새 문구는 미사용 색을 우선 배정한다. 현재 탭 최대 8개. |
| `F1` | 기능과 단축키 도움말 | 현재 기능의 조작 방법을 확인한다. |

줄 번호를 클릭하면 개행을 포함한 해당 물리적 줄 전체를 선택하고 커서는 그 줄에 남는다. **줄 번호에서 왼쪽 버튼을 누른 채 드래그**하면 여러 줄을 선택하고 **Ctrl+줄 번호/본문 클릭**으로 떨어진 줄을 추가·해제한다. 자동 줄바꿈으로 여러 화면 줄이 되어도 같은 물리적 한 줄로 취급한다. 선택 행은 탭마다 보관하며 Ctrl+C는 선택한 표시 행만 원본 순서로 복사한다.

우클릭 메뉴가 열려 있는 동안 작업 대상 줄의 배경·테두리와 줄 번호를 강조한다. 메뉴 머리말에서도 작업 대상 원본 줄 번호를 확인할 수 있다. 행 선택·문구 선택과 우클릭 대상 표시는 별개다.

새 빈 탭은 로그 입력을 기다리는 읽기 전용 자리다. +는 처음 실행하거나 마지막 탭을 닫은 뒤에도 보인다. 빈 탭에서 지원하지 않는 붙여넣기나 열기가 실패하면 그대로 유지하며, 이미 열린 파일을 다시 열면 기존 탭으로 이동하고 빈 탭은 남긴다.

검색 결과 위 경계선을 드래그하면 목록 영역 높이를 바꾼다. 경계선에 포커스를 둔 상태에서는 위·아래 방향키로 조절한다. 결과 제목줄의 **접기 / 펼치기**는 검색과 F3/F4 이동을 유지하며 목록만 접는다. 높이와 접힘은 재실행 시 복원한다. 작은 창의 일시적인 높이 제한은 사용자가 선택한 높이를 덮어쓰지 않는다.

고정 분석 패널을 사용하지 않는다. 로그 줄을 우클릭해 **세션 분리 시작 → 세션 분리 끝 / 새 탭**, **시간 비교 기준 → 기준과 이 줄 시간 차이**, 주변 보기를 실행한다. 시간은 클릭한 줄의 소유 헤더에서 읽고 여백에 A/B 표식을 보인다. 분리 시작·시간 결과는 간단한 표시줄로 안내한다. 결과 복사·이동·해제는 **시간 비교 결과**, 북마크는 **이동·북마크**, 복사·붙여넣기는 **텍스트** 하위 메뉴에 있다.

**Shift+F8**은 선택 문구가 있으면 그 문구를, 없으면 커서 단어를 즉시 강조한다. 다시 실행하면 같은 문구의 규칙을 삭제한다. 문구·색·개별 켜기·삭제는 분석 또는 우클릭 메뉴의 **강조 문구 관리…** 창을 사용한다. ‘추가’만 새 규칙을 등록하고 ‘적용’은 등록된 규칙의 변경만 반영한다. 취소하면 이전 규칙을 유지한다. 색은 6개 팔레트이며 모두 사용 중이면 재사용한다. 공백만인 문구와 4,096자를 넘는 문구는 거절하며 일부만 잘라서 강조하지 않는다.

스레드 목록 위 찾기 입력칸은 목록만 좁힌다. ID 일부, `T123`, `미분류`로 찾고 ×로 전체 목록을 복원한다. 내용 필터 0건에서 내용만 해제하면 스레드 선택을 유지하고, 모든 필터 해제는 전체 기록을 표시한다. 보기 → 스레드별 배경색에서 배경을 끄고 켜며 스레드 마커·검색·문구 강조는 유지한다.

주변 범위는 줄 우클릭 → **주변 로그 범위**에서 5/20/100기록 또는 **직접 지정… (0~10,000)**으로 정한다. 화면 설정은 보기 메뉴, 수동 인코딩은 파일 → 인코딩으로 다시 읽기에 있다.

세션 분리는 시작·끝 원본 물리적 줄을 포함한다. 필터로 숨겨진 중간 줄도 범위에 들어간다. 분리 탭의 전체 원본 검색·주변 보기·줄 이동은 그 범위를 벗어나지 않는다. 같은 탭의 원본 줄 번호를 입력하고 다른 원본 범위는 원래 파일 탭에서 본다.

현재 필터로 숨겨진 북마크·검색 결과·시간 기준점에 이동하면 해당 기록의 앞뒤 주변 로그를 자동으로 연다. 주변 보기 표시줄의 복귀 버튼으로 이전 필터와 위치를 복원한다. 주변 보기에서 스레드·내용 필터 변경은 잠기지만 북마크는 사용할 수 있다. `Ctrl+G`로 숨긴 원본 줄을 입력한 경우에는 안내 후 해당 줄의 주변 로그를 여는 버튼을 사용한다.

원본 로그는 편집할 수 없다. 기능 조작으로 북마크·필터·강조 표시를 바꾸어도 원본 내용은 변경되지 않는다.
